A deterministic Python program that writes one one-line joke — my useless superpower: turning anything into gold, but only things that are already gold — to `/output/entry.txt` for make.fun's "Worst Superpower" bounty.

## Run it

```sh
python3 main.py
```

## How it works

`main.py` (Python standard library only, no network, no randomness) holds one fixed joke string and writes it to `/output/entry.txt`. Two runs produce byte-identical output. See [STUDY.md](STUDY.md) for how the joke was chosen from 28 candidates scored against the judge's brief.
